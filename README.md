#easypy

Easypy is a collection of tools to simplify common code snippets
please notice all functions in easypy end with snakecase with the exception of p()

##p()

p() is just like print but 4 characters shorter

##year_()

year() simply prints the year in 4 Digit format

##day_name_()

day_name_() prints the day name eg, monday

##month_num_()

month_num_() prints the month in number format

##month_str_()

month_str_() prints the month name eg march

##dmy_()

dmy_() prints the date in dd:mm:yyyy format.  type what ever separator you want in the parenthesise
eg dmy_(':') will display dd:mm:yyyy and dmy_('/') will display dd/mm/yyyy  just remember if you want \ you need to type \\

##mdy_()

mdy_() displays the date in the American format mm:dd:yyyy  control the separator the same as dmy_()

##time_stamp_()

time_stamp_() prints the time as a one off non updating format

##time_live_()

time_live_() prints a constantly updating time
